## Tasks

### Task 1: DB 분리 — chain_config.yaml db_path 분리

**파일:** `config/chain_config.yaml`
**변경:** `db_path`를 복제 레포 내 상대 경로로 변경 (기존 5000 공유 해제)
**근거:** RESEARCH.md 1번 — DB 미분리 시 chain_id 재사용 + slug 크로스 발행 위험

**상세:**
- 현재: `db_path: /Users/twinssn/Projects/5000/data/mc_chains.db`
- 변경: 복제 레포 기준 `db_path: data/mc_chains.db` (상대 경로)
- `init_db_path()` (mc_paths.py)가 상대 경로를 절대 경로로 변환하는지 확인 필요

**검증:**
- chain_config.yaml db_path 변경 후 `python -c "from chain_config import load_config; c=load_config(); print(c['db_path'])"` 로 확인
- chain_db.init_db()가 CREATE TABLE IF NOT EXISTS로 신규 스키마 자동 생성하는지 확인

### Task 2: shared vendoring — ai_writer/env_loader/__init__/models.yaml 복사

**파일:** 복제 레포 내 `shared/` 디렉토리
**변경:** 5000 레포의 shared 모듈을 복제 레포에 vendoring
**근거:** RESEARCH.md 2번 — 5000 변경 시 복제 레포 영향 방지

**상세:**
- 소스: `/Users/twinssn/Projects/5000/shared/`
- 대상: 복제 레포 `shared/`
- 파일: `ai_writer.py`, `env_loader.py`, `__init__.py`, `config/models.yaml`
- `mc_paths.py`에서 `PATH_5000` 하드코딩 제거 → vendoring된 shared 사용
- pyproject.toml `include=["shared*"]` 확인

**검증:**
- `python -c "from shared.ai_writer import import test"` 로 import 확인
- `python -c "from shared.env_loader import load_env"` 로 env 로드 확인

### Task 3: R2 매핑 키 추가 — informationhot/5.informationhot

**파일:** `image/r2_uploader.py`
**변경:** `HUGO_R2_DOMAINS`에 informationhot/5.informationhot 엔트리 추가
