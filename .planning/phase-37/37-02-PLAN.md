### Task 1: git 복제 + 원격 교체

**명령어:**
```bash

cd /Users/twinssn/Projects
git clone git@github.com:hugh79757-cmyk/mc.git mc-informationhot
cd mc-informationhot

# 2. 원격 교체 (기존 mc origin과 충돌 방지)
git remote remove origin
git remote add origin git@github.com:hugh79757-cmyk/mc-informationhot.git
# (새 GitHub 레포 먼저 생성 필요)

# 3. 브랜치 정리

```

**주의사항:**
- 새 GitHub 레포 `mc-informationhot` 먼저 생성 필수
- 기존 mc origin 제거 후 새 origin 추가
- `.env`는 git 미추적 → 복제 레포에서 복사 필요
