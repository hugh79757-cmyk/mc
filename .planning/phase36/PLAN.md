### T1 — BUG-001: reasoning_content truncation (생성 복구 최우선)

- **조사**: `shared/ai_writer.py` `generate()` line 127-132 재현(모의+실제), truncation 지점 확인, `finish_reason` 로그 확인

- **검증**:
  - 과목 2: 절단 응답 파싱 단위 테스트
  - 과목 4: 실제 모델 호출 재현 — 파손 응답 발생 여부 실측
  - 과목 7: derive→draft 정상 초안 1건 생성 확인
- **완료 조건**: 재현 케이스에서 JSON 파싱 실패 0건, 정상 초안 산출

### T2 — BUG-002: fallback 4 배열 오인 (파싱 안정화)

### T3 — BUG-006: 파손 초안 발행 선차단 게이트 (안전망)

- **조사**: 발행 경로에 draft_md 계획텍스트 비율 검사 지점 삽입 위치 확정 (chain_publisher_core.py publish 단계)
- **수정 방식(지시 확정)**: **계획텍스트 비율 임계치 게이트** — draft_md 내 지시 문구 패턴(예: `다루어야 합니다`, `작성해야 합니다`, `작성해보겠습니다`, `섹션은`, `플레이스홀더`, `참고 자료`) 밀도를 계수 → 전체 대비 비율이 임계치(예: 20%, 조사에서 산정) 초과 시 `DeployValidationError`로 발행 중단 + 로그
- **검증**:
  - 과목 6: 10006/10007 파손 초안 → 게이트 차단 실증 (dry-run)

  - 과목 5: 차단 로그/산출물 육안
- **완료 조건**: 파손 초안 발행 차단 실증, 정상 초안은 통과 (오탐 0)
