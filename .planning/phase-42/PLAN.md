# Phase 42: 제목-본문 정합성 검증

**Milestone:** M3 — 9점 품질 달성
**Goal:** 블로그 제목이 본문 내용과 일치하는지 자동 검증. AI가 생성하는 제목-본문 불일치 문제 해결.

## Why

AI 초안에서 제목과 본문이 불일치하는 경우 발생. 예: "토마토 맥주 가이드" 제목인데 본문에 토마토 관련 내용 부족. 검색 사용자 기대치와 실제 콘텐츠 괴리 → 이탈률 상승.

## Plan

### W1: title_body_checker.py

- 제목에서 핵심 키워드 추출 (명사구 기반)
- 본문에서 해당 키워드 출현 빈도 검사
- 기준: 제목 핵심 키워드가 본문에 최소3회 출현
- 한글 제목 정규화 (공백·특수문자 무시)

### W2: 검증 규칙

- `validate_title_body(post_md: str) -> TitleBodyResult`
- 제목에서 명사구 추출 (형태소 분석 없이 간단한 패턴 매칭)
- 본문 H2/H3 섹션에서 키워드 존재 확인
- 결과: 일치도 점수 (0.0~1.0) + 위반 목록

### W3: 게이트 통합

- `quality_gate.py`에 제목-본문 검증 추가
- 계약 검증과 동일한 `GateResult` 인터페이스

### W4: pytest

- 제목-본문 일치 케이스 (통과)
- 제목-본문 불일치 케이스 (위반)
- 빈 제목/본문 엣지 케이스

## Dependencies

- Phase 41 (contract_loader.py, quality_gate.py)

## Risks

- 형태소 분석 없이 키워드 매칭하면 오탐 가능 → 관대한 기준으로 시작
