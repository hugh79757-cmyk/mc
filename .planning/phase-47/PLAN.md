# Phase 47: 썸네일 검증 +9점 스코어링 시스템

**Milestone:** M3 — 9점 품질 달성
**Goal:** 썸네일 품질 검증 + 전체 콘텐츠9점 스코어링 시스템 구축

## Why

썸네일은 클릭률에 직접 영향. 전체 파이프라인의 품질을 하나의 점수로 판정해 자동화된 품질 관리 달성.

## Plan

### W1: thumbnail_checker.py

- 썸네일 파일 존재 확인
- 크기 검증 (1200x630 권장, 최소800x420)
- aspect ratio 검증 (1.91:1 근접)

### W2: quality_scorer.py

- 가중합 점수 산출:
  - 계약 충족 (40%): Phase 41 계약서 검증 결과
  - 사실성 (25%): Phase 43 factuality 스코어
  - 역할 분리 (20%): Phase 44 중복 + 역할 검증
  - 시각 품질 (15%): 썸네일 + HTML 렌더링

### W3: 자동 판정 기준

- 7.0미만: 재생성 (다른 키워드로 재시도)
- 7.0~8.9: 수동 검토 후 승인
- 9.0+: 자동 승인

### W4: 기존 image 파이프라인 연동

- image/ 모듈과 통합
- R2 업로드 전 품질 검증

### W5: pytest + e2e 검증

- 스코어링 단위 테스트
- 최소1개 키워드로 e2e 품질 점수9.0+ 달성 확인
- pytest 녹색 유지

## Dependencies

- Phase 41~46 모든 검증 모듈
- 기존 image/ 모듈

## Risks

- 스코어링 가중치가 실제 품질과 안 맞을 수 있음 → 점진적 조정
- 자동 승인 기준9.0이 너무 높을 수 있음 → 초기8.5로 시작 가능
